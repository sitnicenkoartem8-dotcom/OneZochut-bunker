# Бункер: Ван Зошит v1.0

Мультиплеерная браузерная игра для GitHub Pages + Firebase Realtime Database.

## Что нового в v0.9

- Добавлена кнопка **Персонализация** перед входом в игру.
- Игрок может выбрать аватарку из набора мемных заготовок.
- Аватарка видна в лобби, таблице игроков и анализе выживания.
- Добавлена **тёмная/белая тема**.
- Добавлен выбор цвета акцента сайта.
- Добавлены лёгкие оптимизированные анимации карточек, кнопок и аватарок.
- Добавлены звуки интерфейса.
- Добавлена тихая фоновая chiptune-музыка, которая генерируется самим браузером без аудиофайлов.
- Внутри нет чужих музыкальных файлов. Если хочешь конкретный трек, добавь свой разрешённый mp3 отдельно.

## Запуск локально

```bash
py -m http.server 8000
```

Потом открой:

```text
http://localhost:8000
```

Не открывай через `file:///index.html`, иначе браузер может заблокировать модули.

## Онлайн

1. Загрузи файлы на GitHub.
2. Включи GitHub Pages: `Settings → Pages → Deploy from a branch → main → /root`.
3. Firebase Realtime Database должна быть включена.
4. `firebase-config.js` уже должен содержать твой config.

## Файлы

- `index.html` — структура сайта.
- `style.css` — стиль, темы, анимации.
- `data.js` — карты, события, катастрофы, режимы.
- `app.js` — мультиплеер, комнаты, голосования, Помидоры, персонализация.
- `firebase-config.js` — подключение к твоей Firebase.
