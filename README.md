# Бункер: Ван Зошит v0.4

Версия с реальными событиями раунда, картой характера, фобиями, режимами бреда и рабочими Помидорами.

## Что изменилось в v0.4

- Добавлена карта **Характер**.
- Карта **Секрет** заменена на **Фобию**.
- События раунда теперь реально влияют на игру:
  - уменьшают вместимость бункера;
  - иногда оставляют только 2 места;
  - мутируют расу игрока;
  - меняют карты игроков местами;
  - дают дебафф здоровью;
  - бафают Картошек до суперкачков;
  - блокируют Помидоры на раунд;
  - дают +1 раскрытие карты;
  - запускают двойной вылет.
- Когда ведущий создаёт или обновляет событие, всем игрокам появляется уведомление.
- Режимы бреда стали сильнее отличаться:
  - **Нормальный** — меньше мемов, больше выживания.
  - **Мемный** — смешные предметы и нормальный хаос.
  - **Бредовый хаос** — больше абсурдных карт и выше шанс жёстких событий.
- Помидоры по-прежнему применяются кнопкой на своей карте. Авто-Помидоры срабатывают сами.

## Как запустить локально

1. Открой папку проекта.
2. В адресной строке проводника напиши `cmd`.
3. Введи:

```bash
py -m http.server 8000
```

4. Открой в браузере:

```text
http://localhost:8000
```

Не открывай `index.html` напрямую через `file:///`, иначе браузер может заблокировать JavaScript-модули.

## Мультиплеер

Мультиплеер работает через Firebase Realtime Database. В архиве уже лежит `firebase-config.js`, который был настроен для проекта One Zochit.

Для публичного запуска через GitHub Pages просто загрузи все файлы в репозиторий и включи Pages.

## Важно про безопасность

Тестовый режим Firebase подходит для проверки, но для публичной версии лучше потом настроить правила базы, чтобы комнаты нельзя было ломать случайными запросами.
